A few minutes to get started.

Start with dictation. Add the local assistant when you're ready.

  1. Download & extract

    Get the Windows ZIP from GitHub Releases. Extract the folder and run WritHer.exe.

  2. Let the model load

    The speech model downloads on first launch. You'll need an internet connection for this step.

  3. Hold a key & speak

    Focus a text field, hold AltGr, speak, then release. Change shortcuts or recording mode in Settings.

A few good questions.

Read the WritHer FAQ ↗
Is WritHer really free?

Yes. WritHer is open source under the MIT license, with no subscription or paid dictation tier. You can use it, inspect it, modify it and contribute.

Do I need Ollama for dictation?

No. Speech-to-text works on its own with faster-whisper. Only the voice assistant needs a language model, through Ollama or another supported local server.

Does it work offline?

Dictation works offline after the speech model has downloaded. The assistant also works offline when its server and model run locally. Choosing a remote server changes where assistant requests are sent.

Can I use it on macOS or Linux?

WritHer currently supports Windows 10 and 11. Contributions towards other platforms are welcome. See the contribution guide.

A free, offline alternative to Wispr Flow.

If you're looking for speech-to-text on your own Windows PC, WritHer gives you local dictation and an open-source voice assistant. Compare the approaches and choose what fits your workflow.
